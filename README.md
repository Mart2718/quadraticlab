# PR1 Quadratic Graph Lab

An interactive Math 172 learning tool for graphing quadratic functions and identifying vertices, axes of symmetry, real roots, and maximum or minimum points.

## Files

- `index.html` - main page
- `styles.css` - visual design and responsive layout
- `app.js` - graphing, guided practice, Standard Form Lab, and skill check
- `netlify.toml` - Netlify deployment settings

## GitHub

Upload all four website files and this README to the top level of one GitHub repository. Keep `index.html` at the repository root.

## Netlify

Connect the GitHub repository to Netlify. No build command is needed. The publish directory is the repository root (`.`).
